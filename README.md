# 图片参数随机生成器

一款 macOS 桌面工具，可为 JPG、PNG、WebP 图片的副本写入随机的模拟相机参数。支持拖入多张图片或文件夹，也可用按钮选择文件。

## 下载与使用

1. 下载仓库中的 `图片参数随机生成器-macOS.zip` 并解压。
2. 打开“图片参数随机生成器.app”，选择或拖入图片。
3. 根据需要选择机型、镜头和光线范围，再点击“开始处理”。
4. 默认在桌面的“图片参数处理结果”文件夹查看副本；也可以选择其他输出位置。

下载包内是 Apple 芯片（arm64）版本，在 macOS 26 上构建和测试。输出默认沿用原文件名，若存在同名文件会自动加序号，不覆盖原文件。文件夹仅扫描第一层。

机型包括 iPhone 14 Pro、15 Pro、16 Pro。ISO 与快门按范围随机；镜头类型对应相应的焦距与固定光圈，镜头名称会带等效焦距和光圈。参数写入文件元数据，不会重绘图片，也不代表该图片真实由对应设备拍摄。

部分社交软件在传输或压缩时可能移除元数据；不同照片应用对镜头信息的显示方式也可能不同。含数字来源凭证的原图经过元数据修改后，其凭证验证状态可能发生变化。

## 从源码构建

需要 macOS、Xcode Command Line Tools、系统 Perl、Git 和网络访问。运行：

```bash
chmod +x build.sh
./build.sh
```

脚本从 ExifTool 官方仓库获取固定版本，在 `build/` 下创建应用，使用本机 Swift 编译并进行临时本地签名。它默认针对本机架构和系统构建；未在所有 macOS 版本上测试。
